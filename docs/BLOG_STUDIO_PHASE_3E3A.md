# Phase 3E.3A — opt-in text publication UI

Stacked on verified #72 (188 SQL and 234 local API checks). Adds narrow RPC client and strict response validation, and a publication panel for saved drafts only, gated by both VITE_ENABLE_BLOG_DRAFTS and VITE_ENABLE_BLOG_PUBLICATION. Default off. Publish/republish requires clean saved revision, no media references and available generation budget; removal affects public snapshot only. Explicit confirmation, generation/revision CAS, exact request retry while panel mounted, live status re-read after receipt, and access denial clears workspace. On switching drafts/reloading/access recheck, the panel remounts and reads authoritative state; uncertain request keys are in memory only. No hosted media delivery, no media publish UI, no flag activation or deployment. Unit tests added; browser acceptance and further lifecycle UX tests remain. CI pending.
