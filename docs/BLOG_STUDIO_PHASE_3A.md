# Phase 3A — local Blog Studio workspace

Scope: stacked on planning PR #51. No hosted settings, dependencies, database writes, migrations or publishing. VITE_ENABLE_BLOG_EDITOR is false by default; the local OAuth launcher sets it true. Existing RequireBlogAdmin remains authoritative and unmodified. The editor has no Data API write or storage code. No drafts are persisted to local/session storage, files or network. Private workspace is noindex as before.

Workspace: up to 20 temporary drafts, title/summary/slug/category/tag/byline/SEO fields, searchable library, add/reorder/remove heading, paragraph, quote, list, code blocks, formatted text parts with bold/italic and optional safe links, preview via BlogArticle. No raw HTML or contentEditable; React text escapes all input. Preview links are non-navigable. The versioned rich-paragraph v1 shape is explicitly parsed in the public reader (legacy blocks unchanged); new blocks are not written to any database in this phase. 100 blocks, 50 runs per paragraph, 10k characters per field, 1 MiB per draft, existing metadata field caps. Draft metadata/slug validation is provisional; server validation and unique slug constraints are Phase 3B. Empty drafts can be previewed with placeholders; dates in preview are not publication dates.

Known limitation: the existing fail-closed gate unmounts children during auth revision/focus/pagehide rechecks, even if access is subsequently granted. This deliberately clears the memory-only workspace, including when switching windows. The banner states this, and beforeunload warns about normal navigation. This is a prototype, NOT a production authoring tool. Phase 3B must resolve durable draft saving before real writing. No autosave/saved indicator, no upload/cover/media, no archive or publish controls in 3A. Formatting applies to explicit text parts, not arbitrary selection. No paid library added.

Acceptance: strict rich-run decoder rejects malformed/unknown versions, extra keys, unsafe URLs; shared render escapes scripts; test add/edit/reorder/remove, search, preview, link safety, authorization loss clears workspace, mobile layout and disabled-by-default build. CI remains separate from real local OAuth/manual device testing. No merge without explicit approval.
