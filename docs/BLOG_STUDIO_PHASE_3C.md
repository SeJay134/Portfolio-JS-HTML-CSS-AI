# Phase 3C — local Studio photo compression

Stacked on #54. New opt-in VITE_ENABLE_BLOG_PHOTOS (default off; isolated OAuth launcher true). Lazy loaded only inside the authorized Studio workspace. No uploads, storage buckets, draft media references, image blocks or hosted changes. Existing public Photo Compressor unchanged; reuse its JPEG/ZIP functions and the same adult-only fail-closed screen. No new dependencies.

Queue accepts at most 300 files, 25 MiB/file, 1 GiB selected total; existing moderation preprocessor enforces 40 MP after decode. Sequential screening and compression; valid output JPEG <= requested decimal KB, dimension <=2200, default 300 KB (20–5000 KB range); 100 MiB cumulative retained output. Limits are conservative, not a device-memory guarantee. Input file references released on success or block; failed/cancelled files retained for retry. Only completed verified outputs appear in preview/download. One preview object URL at a time, revoked on replacement/removal/unmount; ZIP is optional and explicitly prepared/downloaded, invalidated on mutation. Cancellation aborts future work and retains already completed photos; in-flight browser codec/model work may not be immediately interruptible. Blocked files cannot be retried without new selection. Confirmation resets on replacement; no safety bypass. Existing public tool policy not changed. Model is adult-only, best effort, not complete content/legal review.

No persistent browser photo cache. A gate recheck/focus/pagehide or logout can unmount the workspace and discard the queue; downloads are explicit. Originals stay on device; no image network payloads, only normal app/model asset requests. Real iPhone picker/HEIC/memory and actual model performance remain manual final acceptance items; deterministic tests use safe synthetic inputs and mocks. Phase 3D must independently validate actual bytes and server access, provide private media storage and attach verified assets; do not treat client results as security proof. No publication or production activation.

PR #54 at initial review: Windows/frontend, draft browser tests, SQL/API and Vercel Preview passed; final browser regression was still running. Do not merge this or its stacked parents without separate approval.
