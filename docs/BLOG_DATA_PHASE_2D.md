# Phase 2D — public data integration

This PR does not change Supabase schema, environment variables, admin accounts or production data. The existing empty static catalogue remains default. Use VITE_ENABLE_LIVE_BLOG=true only in a reviewed test environment with Phase 2B/C schema and a publishable key. The public reader makes direct read-only Data API requests with apikey only, no account JWT, no cookies, no persistent caching, no service-role key. RLS remains authoritative; query filters and runtime validation additionally reject draft, archived and future-dated data. Public taxonomy is nested through existing foreign keys. Article requests fetch content by exact validated slug, catalogue fetches metadata only with 50-row pages and a hard 500-post limit (error rather than silently truncate). Search/categories operate on the loaded catalogue. No fallback to old static content in live mode.

The separate Vercel article shell serves dynamic slug routes, requires JS, is noindex/nofollow and does not contain content at build time. Verify Vercel routing in preview (including trailing slash, direct refresh and 404 behavior). Vite preview does not implement Vercel rewrites. Dynamic not-found is an application state, not an HTTP 404; server-rendered article HTML, canonical/metadata, sitemap/RSS, true 404/503 and unpublish cache invalidation are launch blockers before real publication. Existing static catalogue SEO remains. Live build refuses nonempty static article source; do not add static articles while using dynamic rewrite. Real content remains unpublished; the approved launch pipeline should use current public rows at request time or explicit safe rebuild/invalidation. Focus and back-forward cache revalidation reduce stale display; already rendered/copied content cannot be recalled.

No new dependency or paid service. Future media storage needs separate security review. Tests use synthetic fixtures, not live credentials. Production deployment of this PR is not authorized by its creation.

Preview review: initial rewrite matched only the slashless route, while article links end with a slash. Explicit trailing-slash rewrite and noindex/no-store response headers added. Live-mode CI runs a separate compiled build with synthetic intercepted API responses. It verifies browser behavior, not the real hosted Supabase gateway. Optional related catalogue loading no longer blocks article rendering; prerendered live catalogue no longer claims there are no publications before the request.
