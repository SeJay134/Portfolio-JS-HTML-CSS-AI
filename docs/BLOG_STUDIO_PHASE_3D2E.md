# Phase 3D.2E — optional isolated local HTTP service

Stacked on #60: 131 SQL, 109 real local API and 18 Python tests passed. This increment introduces a working loopback HTTP boundary, not a hosted endpoint. No new migration or dependency.

Optional launcher mode `python scripts/oauth-staging.py --media` requires a dedicated Python 3.12 environment installed with the existing hash-pinned requirements-studio-media.txt. Existing smoke/default modes unchanged. Only a fresh isolated staging stack's generated JWT secret is passed via child stdin, never Vite, command line, browser or logs. Bind 127.0.0.1:5512 only, no tunnel. Stop child before removing staging stack. The local signing secret is powerful and resides in the local service process; this is deliberately NOT a hosted credential architecture. Do not expose or deploy. No new user manual test required for this increment.

Strict Host and Origin, exact POST routes, bearer token, 1 KiB JSON body cap, no cookies, no redirects/proxy to Data API, response no-store, generic errors, serial request handling. CORS allows only the dedicated local app origin. The actual user's signed token is forwarded to the broker, which obtains server-authorized grant context; worker capability remains server-side. Returns verified asset metadata only; no token or owner ID. Retry uses existing immutable promotion and cleanup. HTTP error does not imply rollback. Only local request tests and real loopback API tests; not production-grade ingress/OS sandbox. No browser UI calls yet.

Quota release is intentionally not implemented: a Storage metadata absence check alone cannot prove that an indefinitely delayed upload has no orphaned bytes. Rejected tombstones remain counted. Automatic cleanup scheduling requires a separate narrowly authorized maintenance identity and bounded reconciliation; no active user session impersonation or global signing key in hosted functions. The production issuer/hosting architecture remains open. Next: gated local upload/preview and media references, with explicit local-only limitations. No production activation or merge.
